# 炫音播放器（Mp3Player）

一款 Windows 桌面 MP3 播放器，使用 C# / WPF（.NET 8）开发。
深色科技风 + 玻璃拟态 + Neon 霓虹光晕，类似酷狗概念版的本地播放器。

## 运行

直接双击 `publish\Mp3Player.exe` 即可运行，无需安装 .NET。
程序为单实例，重复启动会提示已在运行。

## 功能

- 播放 MP3 / WAV / FLAC / M4A 等音频文件
- 点击按钮或拖拽文件添加歌曲，也可以一键添加整个文件夹（自动扫描子目录），播放列表自动保存，下次启动自动恢复
- 自动读取歌曲内嵌封面、歌名、歌手、专辑信息，封面模糊后作为窗口背景
- 320px 黑胶唱片：蓝紫光环 + 黑胶纹理 + 旋转播放 + 复古唱臂（播放时落下）
- 酷狗式实时频谱：64 根律动光柱（FFT 真实频谱 + 对数频率映射 + dB 动态归一化，每根柱独立律动），上下镜像 + 水面倒影 + 霓虹发光
- 频谱细节：深色玻璃面板（无边框）、顶部漂浮粒子光点、暂停/停止时频谱完全静止
- 深色渐变窗口背景 + 左右紫色/蓝色光晕 + 封面模糊背景
- 60px 自定义标题栏：渐变 Logo + 标题 + 副标题
- 歌曲信息显示格式标签（如 MP3 / 44.1kHz / 320kbps）
- 播放按钮 80×80 渐变圆形 + 呼吸动画
- 均衡器自绘滑块：渐变轨道 + 发光圆点
- 音量滑块带百分比显示和声音图标（静音/低/高自动切换）
- 顺序播放 / 单曲循环 / 随机播放三种模式
- 播放模式点击后弹出菜单选择，一目了然
- 5 段均衡器（低音 / 中低 / 中音 / 中高 / 高音，-12dB ~ +12dB）
- LRC 歌词解析（主窗口逐行高亮 + 桌面歌词悬浮窗）
- 迷你模式、系统托盘（关闭窗口即最小化到托盘）
- 全局快捷键（键盘媒体键 / Ctrl+Alt 组合键）
- 记住音量、播放位置、窗口大小与位置；播放列表变动即时保存，异常退出也不丢
- 记住上次播放位置，重新打开自动恢复到该进度
- 打开淡入、最小化/隐藏到托盘淡出、最大化缩放过渡动效

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 快退 / 快进 5 秒 |
| ↑ / ↓ | 音量 + / - |
| Ctrl + ← / → | 上一曲 / 下一曲 |
| Ctrl + Alt + P / N / B | 播放暂停 / 下一曲 / 上一曲（全局） |
| 键盘媒体键 | 播放暂停 / 切歌（全局，低级键盘钩子，兼容性最好） |

## 歌词

将歌词文件命名为与歌曲相同并放在同一目录，例如 `歌曲名.mp3` 对应 `歌曲名.lrc`，
支持 UTF-8 和 GBK 编码。

## 数据位置

播放列表、音量、均衡器等设置保存在 exe 同目录的 `data\settings.json`，
删除该文件即可恢复默认设置。

## 开发

- 源码在项目根目录，入口为 `App.xaml` / `MainWindow.xaml`
- 编译：执行 `env.bat` 后运行 `dotnet publish -c Release -r win-x64 --self-contained true -o publish`
- `.dotnet`（SDK）、`.nuget`（包缓存）、`bin`、`obj` 均为开发产物，发布只需 `publish` 目录
